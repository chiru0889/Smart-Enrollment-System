# 🎓 Smart Enrollment System

A modern, intelligent enrollment management system built with JavaScript. This advanced platform provides an enhanced enrollment experience with smart features for efficient student registration and management.

## ✨ Features

- **Smart Registration**: Intelligent form with auto-validation
- **Real-time Feedback**: Instant validation messages for user guidance
- **Student Database**: Comprehensive student information management
- **Enquiry Tracking**: Monitor and manage all student inquiries
- **Advanced Search**: Find and filter student records easily
- **Responsive Design**: Works seamlessly on all devices
- **Error Handling**: Robust error management and user feedback

## 🛠️ Tech Stack

- **Frontend**: Modern JavaScript (ES6+)
- **Markup**: HTML5
- **Styling**: CSS3 with responsive design
- **Architecture**: Object-oriented JavaScript patterns

## 📋 Getting Started

### Prerequisites
- Modern web browser (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- Git
- Text editor or IDE

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/chiru0889/Smart-Enrollment-System.git
   cd Smart-Enrollment-System
   ```

2. **Open with live server**
   ```bash
   # Option 1: Using VS Code Live Server extension
   # Right-click index.html → Open with Live Server
   
   # Option 2: Using Python
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

3. **Or simply open in browser**
   ```bash
   # Double-click index.html to open directly
   ```

## 🎯 How to Use

### For Students
1. Navigate to the enrollment page
2. Fill in personal and academic details
3. Select desired course/program
4. Submit application
5. Receive confirmation and next steps

### For Administrators
1. Access the admin dashboard
2. View all student applications
3. Filter by status, course, or date
4. Approve/reject enrollments
5. Send notifications to students
